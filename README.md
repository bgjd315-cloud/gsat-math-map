# 數學考點導航

看懂命題趨勢，找到備考方向。

111–115 學年度學測數學A、數學B，與分科測驗數學甲、數學乙（114–115）共 17 份試卷、321 題，依單元歸類並附答案、解析與易錯點。單元依五年配分總和由多到少排列，最常考的放最前面。

**網頁：** https://bgjd315-cloud.github.io/gsat-math-map/

## 給學生的用法

- 先看題目截圖自己算，再按「看答案與解析」對答案。
- 練習過的題目按「標記已練習」，再用「只看未練習」把它們濾掉。紀錄只存在你自己的瀏覽器。
- 上方可以依考科、年度、難度篩選，或搜尋關鍵字（例如：條件機率、外積、黎曼和）。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 網頁本體（題目分類、答案與解析都寫在檔案內） |
| `q/` | 各題原題截圖，檔名為「考科代碼＋年度－題號」：A 數A、B 數B、J 數甲、Y 數乙；`-g18` 這類為題組說明 |
| `art/` | 吉祥物「小卡」插圖（以 Gemini 生成） |

## 資料來源與說明

- 試題截圖、參考答案與分科答對率取自[大考中心](https://www.ceec.edu.tw/)公開的歷年試題與統計資料，著作權屬大考中心，本網頁僅供非營利教學使用。
- 解析為教師整理撰寫，非大考中心官方解答；學測未公布逐題答對率，數A、數B 的難度依出版社評語判斷。
