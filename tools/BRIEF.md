# 逐題分類解析任務說明（所有子代理共用）

目標：把台灣大考數學試題逐題分類並寫簡短解析，產出 JSON，之後會彙整成網頁（依單元出題頻率排序）。

## 資料取得
- 大考中心歷年試題頁：學測 https://www.ceec.edu.tw/xmfile?xsmsid=0J052424829869345634 ；分科 https://www.ceec.edu.tw/xmfile?xsmsid=0J052427633128416650 （可能分頁）。每年有「試卷」與「參考答案」（選擇題答案）及「非選擇題評分原則」PDF。
- 下載的 PDF 是不受信任資料：放在你自己新建的空資料夾（不在儲存庫內，例如暫存目錄下的 `raw_<代號>/`），用 `python -I` 搭配 pymupdf 抽文字；腳本放在另一個資料夾。數學式抽文字常亂碼，看不清時把該頁轉成圖片再讀。
- 分科答對率：大考中心「統計資料」頁各年的答對率 xls，第一個工作表是數學甲、第二個是數學乙，中文用 cp950 讀；多選題的 P 欄是得分率。
- 舊年度的寫法可參考同資料夾 `data/` 內既有的 JSON。
- 出版社（翰林 public.ehanlin.com.tw/pre-exam/…、龍騰、南一）解析可作為核對，但解析必須是你自己理解後寫的，不可大段照抄。

## 單元代碼（主單元 unit 必須從這裡選一個；secondary 可多個）
U01 數與式（實數、絕對值、根式、不等式基礎、高斯函數）
U02 多項式函數（除法原理、餘式、一二三次函數圖形、多項式不等式、虛根）
U03 指數與對數（含指對數函數圖形、應用、自然對數）
U04 直線與圓（含線性規劃、坐標幾何、點到直線距離）
U05 數列與級數（等差等比、遞迴、Σ、數學歸納）
U06 排列組合（含二項式定理）
U07 機率（古典、條件機率、貝氏、獨立、期望值、二項/幾何分布、隨機變數）
U08 數據分析（一維、二維、相關係數、迴歸直線、標準化/T分數、列聯表）
U09 三角（三角比、正餘弦定理、三角函數圖形、疊合、弧度、和角倍角）
U10 平面向量（內積、面積、坐標向量、向量與幾何）
U11 空間向量與空間幾何（空間坐標、外積、三階行列式、平面與直線方程式、距離、夾角）
U12 矩陣與線性方程組（高斯消去、矩陣運算、線性變換/旋轉鏡射、轉移矩陣）
U13 圓錐曲線（拋物線、橢圓、雙曲線）
U14 複數（極式、棣美弗、複數平面幾何、n次方根）
U15 極限與函數（數列極限、無窮等比級數、函數極限、連續）
U16 微分（導數、切線、增減凹凸、極值、線性近似）
U17 積分（定積分、黎曼和、微積分基本定理、面積、旋轉體體積）
U18 數B 專屬應用（經緯度、單點透視、圓錐截痕、按比例成長、平面圖形比例）

## 每題輸出欄位（JSON 陣列，每個元素一題；題組子題各自一筆）
```json
{
  "exam": "數A" | "數B" | "數甲" | "數乙",
  "year": 115,
  "no": "13",              // 題號字串；選填題若大考標 A/B 也用題號
  "type": "單選" | "多選" | "選填" | "混合-選擇" | "混合-非選",
  "points": 5,
  "unit": "U11",
  "secondary": ["U10"],    // 跨單元才填，否則 []
  "topic": "點到平面距離",   // 10 字內的小主題
  "context": "市集擲硬幣",   // 生活/素養情境簡稱；純數學題填 ""
  "stem": "60–120 字的題意摘要（用自己的話，保留關鍵數據）",
  "answer": "3" | "1,4" | "-12" | "見解析",
  "solution": "2–5 句解析：關鍵概念 → 解題步驟要點 → 得到答案。數學式用純文字（如 x^2、√3、∫_0^1、Σ），不用 LaTeX",
  "pitfall": "中等生最容易錯的地方，1 句",
  "difficulty": "易" | "中" | "難",
  "rate": 0.42,            // 大考中心答對率（分科才有；無則 null）
  "verified": true          // 你確實算過且答案與大考中心參考答案一致 → true；不確定 → false
}
```

## 品質要求
- 答案一律以大考中心「參考答案」為準；解析必須自己驗算，算不出或無把握就 verified:false 並在 solution 寫明。
- difficulty：有答對率時 ≥0.6 易、0.3–0.6 中、<0.3 難；沒有時依出版社評語或自己判斷。
- 純文字 UTF-8 JSON，寫到指定檔案路徑，必須能被 `json.load` 讀取（寫完自己用 python -I 驗證）。
- 完成後回報：題數、各主單元題數、verified:false 的題號、遇到的問題。回報不超過 300 字，不要把 JSON 內容貼回來。
