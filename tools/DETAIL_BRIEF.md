# 詳細解析撰寫規範（第二版：KaTeX、公式框、鷹架）

讀者是**中等程度的高中生**（大考成績在均標到前標之間）：課本公式學過但不熟，看到長題目會慌，常卡在「不知道從哪裡下手」。網頁上，學生先看「想法」，再一步一步點開，最後才看答案。

全文繁體中文、台灣用語（「坐標」不寫「座標」），語氣中性、句子短，不寫空泛的客套話，不用表情符號。

## 你會拿到

- 題目原圖：`q/`，對照表 `tools/img_manifest.json`（鍵 `"考科|年度|題號"`，題組會先列題組說明圖 `-gNN.png`）。**每題都要用 Read 打開原圖**，數字、圖形、選項以原圖為準。
- 既有資料：`tools/data/*.json`（已核對的 `answer`、`unit`、`topic`、`pitfall`）。
- 第一版詳解：`tools/detail/*.json`（推理已驗算過，可當底稿，但數學式是 Unicode，要全部改寫成本規範的格式）。
- 分科非選題：大考中心「非選擇題評分原則」抽出的文字在暫存資料夾（路徑寫在你的任務說明裡；只讀取，不要在那裡執行程式）。

## 一、數學式通則（KaTeX）

1. 所有數學式、數值、變數、點名一律寫在 `$…$` 內。純文字不得出現 √、½、²、³、⁻¹、x₁、→、≤、≥、≠、×、÷、π、θ、∠、△、⊥ 這類 Unicode 數學符號；一律寫成 `$\sqrt{2}$`、`$x^2$`、`$x_1$`、`$\le$`、`$\times$`、`$\pi$`、`$\theta$`。
2. 分數一律直式，行內也用 `\dfrac`：`$\dfrac{3}{4}$`、`$\dfrac{a+b}{c+d}$`。不得寫 `3/4`、`(a+b)/(c+d)`。
3. 唯一例外：指數位置的分數用橫式，例如 `$x^{3/2}$`、`$2^{-1/2}$`。
4. 除了第 3 點與 `\text{}` 內，`$…$` 內不得出現斜線「/」。
5. 根號化成最簡根式：根號內無平方因數、分母不含根號。
6. 度數寫 `$30^\circ$`；同一題不混用度與弧度。
7. 太長的式子拆成兩步寫，不要一行塞太長（手機寬度約 20 個字）。
8. 數字與中文之間不必加空格；`$…$` 前後緊接中文即可。

## 二、符號體例

線段 `$\overline{AB}$`；弧 `$\overset{\frown}{AB}$`；角 `$\angle ABC$`；三角形 `$\triangle ABC$`；相似 `$\sim$`；全等 `$\cong$`；單一字母向量 `$\vec{u}$`；兩點向量 `$\overrightarrow{AB}$`（不用粗體）；內積 `$\vec{u}\cdot\vec{v}$`；外積 `$\vec{u}\times\vec{v}$`；矩陣 `\begin{bmatrix}…\end{bmatrix}`；行列式 `\begin{vmatrix}…\end{vmatrix}`；數列 `$\langle a_n\rangle$`；求和 `$\sum\limits_{k=1}^{n}$`；常用對數 `$\log x$`（學測、數乙範圍不用 `\ln`；數甲微積分可用 `\ln`）；排列組合 `$P^n_r$`、`$C^n_r$`、`$H^n_r$`（不用 `\binom`）；條件機率 `$P(A\mid B)$`；多項式次數 `$\operatorname{deg}$`；絕對值 `$\lvert x\rvert$` 或 `$|x|$`；積分 `$\displaystyle\int_0^1 f(x)\,dx$`。

## 三、答案與近似值

1. 能寫精確值就寫精確值。
2. 除不盡時，先寫精確式，再附近似值並標明取位：`$20\sqrt{3}$（$\approx34.6$，四捨五入到小數第一位）`。
3. 不得只寫一個沒頭沒尾的近似值。中間過程多留一位，最後一步才取位。
4. 所有算式與答案都要逐一重新驗算。

## 四、每題輸出（JSON 物件）

```json
{
  "exam": "數A", "year": 115, "no": "13",
  "idea": "想法：一到三句，這題的切入點",
  "formulas": [
    {"name": "條件機率（必背）", "tex": "P(B\\mid A)=\\dfrac{P(A\\cap B)}{P(A)}",
     "vars": [["A", "已知發生的事件"], ["B", "要求機率的事件"]],
     "cond": "$P(A)>0$"}
  ],
  "steps": [
    {"q": "引導提問", "calc": ["一行一式", "一行一式"], "why": "必要時補一句理由"}
  ],
  "answer": "$\\dfrac{9}{10}$",
  "approx": "",
  "check": "代回或合理性檢查，一句",
  "wrong": [{"opt": "(C)", "how": "這個選項是怎麼算出來的"}],
  "tiers": [["列式", "…"], ["運算", "…"], ["結論", "…"]],
  "takeaway": "一句話心法",
  "answer_issue": ""
}
```

### idea（想法）
對應原本的「破題引導」：用一到三句講這題在問什麼、關鍵條件是哪幾個字、該聯想到哪個觀念。不在這裡算。

### formulas（公式框）
- 1–3 個本題會用到的公式。每個固定四項：`name`（可註明「必背」或「要會推」）、`tex`（**不含** `$`，整條公式的 KaTeX 原始碼）、`vars`（逐一列出每個符號代表什麼：`[符號的 KaTeX（不含 $）, 意義]`）、`cond`（只有真的有使用限制才寫，可含 `$…$`；沒有就留空字串）。
- `vars` 只列公式裡真的出現、學生可能不懂的符號。

### steps（鷹架步驟）
- 一般題 3–6 步；多選題依 (1) 到 (5) 順序逐項判斷，每一或兩個選項一步，每項都說明對錯理由；非選題依得分點分步。
- `q`：學生在這一步應該問自己的問題，讓他可以先停下來想。可含 `$…$`。
- `calc`：這一步的算式，**一行一式、由上往下推，不跳步**。每行是一個字串，可以混合短中文與 `$…$`，例如 `"由 $Q$：$h=d\\tan60^\\circ=\\sqrt{3}\\,d$"`。不要在 calc 寫「答」。
- `why`：只有這一步的做法不直觀時才補一句理由（中等生會卡住的地方），否則留空字串。
- 情境題的第一步示範如何把文字翻成數學（設變數、畫圖、列表），用 calc 寫出設定。
- 不要寫「步驟一」「步驟二」這種標籤，網頁會自動編號。

### answer、approx
- `answer`：答案本身，可含 `$…$`；單選寫 `(3)`，多選寫 `(1)(4)`，選填寫數值（用 `$…$`）；有小題時 `(1) … (2) …` 全部列出，涵蓋題目問的每一項。
- `approx`：答案除不盡時的近似值說明，例如 `$\\approx34.6$（四捨五入到小數第一位）`；不需要就留空字串。

### wrong（常見錯誤，只有單選題寫）
- 只挑**真有代表性**的錯誤選項，0–2 個；每條都要自己算過，確認那個錯誤算法真的會得到該選項的數字。例：`{"opt": "(4)", "how": "把 $P(A\\mid B)$ 和 $P(B\\mid A)$ 搞反，算成 $\\dfrac{3}{5}$"}`。
- 沒有明確的錯誤來源就給空陣列，不要硬湊。

### tiers（分項說明，只有分科非選題寫）
- 依「列式／運算／結論」分項，一項一句，句子要短，對照大考中心評分原則。**不得出現「級分」或「學測」字樣。**
- 學測題與選擇題給空陣列。

### check、takeaway
- `check`：代回原條件、估算大小或檢查範圍，一句。
- `takeaway`：一句話帶走的解題心法。

### answer_issue
與既有 `answer` 一致就留空字串；若看原圖後發現既有答案有誤，在這裡寫明並在 `answer` 填正確答案。

## 五、輸出檔與檢查

- 寫到任務說明指定的 `tools/detail2/<代碼><年度>.json`，內容是陣列，每題一個物件（題組子題各一個），題數與 `tools/data` 該卷相同。
- **用 Python 產生 JSON**（`json.dump(..., ensure_ascii=False, indent=1)`），在 Python 原始碼裡把含反斜線的 KaTeX 字串寫成 raw string（`r"\dfrac{1}{2}"`），避免跳脫錯誤。Python 一律用 `python -I` 執行。
- 寫完執行檢查器：`python -I tools/check_tex.py tools/detail2/<檔名>.json`（會檢查 Unicode 數學符號、橫式分數、`$` 是否成對、`$…$` 內的斜線等），**修到零錯誤**才算完成。
- 交出前自我檢查：有沒有橫式分數、`$…$` 外的數學式、`$…$` 內的斜線、Unicode 根號與上下標、沒標取位的近似值、漏掉的小題編號，以及沒有驗算過的答案。
- 回報不超過 150 字：題數、`answer_issue` 題號、遇到的問題。不要把 JSON 內容貼回來。不要修改 `tools/detail2` 以外的檔案。
