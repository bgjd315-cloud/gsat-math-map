# 詳細解析撰寫說明（破題引導＋鷹架）

讀者是**中等程度的高中生**（大考成績在均標到前標之間）：課本公式學過但不熟，看到長題目會慌，常卡在「不知道從哪裡下手」。解析的目標是讓他**自己走完一遍**，而不是看懂老師的捷徑。

## 你會拿到

- 一組題目（例如 115 學測數A 全部 20 題）。
- 每題的既有資料在 `tools/data/*.json`（已驗算過的 `answer`、`unit`、`topic`、`stem`、`solution`、`pitfall`）。
- 每題的原題截圖在 `q/`；對照表 `tools/img_manifest.json`，鍵是 `"考科|年度|題號"`（例如 `"數A|115|13"`），值是圖檔名清單（題組會先列題組說明圖 `-gNN.png`）。**一定要用 Read 工具打開截圖看原題**，題目的數字、圖形、選項以截圖為準，不要只靠 `stem` 摘要。
- 單元代碼與 JSON 格式另見 `tools/BRIEF.md`。

## 每題輸出（JSON 物件）

```json
{
  "exam": "數A", "year": 115, "no": "13",
  "guide": "破題引導，2–4 句",
  "know": ["先備觀念或公式 1", "公式 2"],
  "steps": [
    {"q": "引導提問", "a": "這一步的做法與理由"},
    {"q": "…", "a": "…"}
  ],
  "answer": "與 tools/data 既有 answer 相同",
  "check": "驗算或合理性檢查，1–2 句",
  "takeaway": "一句話帶走的解題心法",
  "answer_issue": ""
}
```

### guide（破題引導）

用學生的口吻帶他讀題：
1. 這題**到底在問什麼**（換成一句白話）。
2. 題目裡**最關鍵的條件／字眼**是哪個（例如「不放回」「至少」「垂直」「恰好」）。
3. 看到這個條件應該**聯想到哪個觀念**（說出觀念名稱，例如「條件機率」「外積求法向量」）。

不要在 guide 裡直接算。

### know（先備觀念）

1–3 項，把會用到的公式**完整寫出來**，例如 `"條件機率：P(B|A) = P(A∩B) ÷ P(A)"`、`"點到平面距離：|ax₀+by₀+cz₀+d| ÷ √(a²+b²+c²)"`。學生看這裡就能回想課本。

### steps（鷹架步驟）

- 一般題 3–6 步；多選題可以到 8 步（每個選項或每兩個選項一步，**每個選項都要判斷對錯並說理由**）；非選擇題照評分原則的得分點分步。
- `q`：學生在這一步應該問自己的問題，例如「題目給的兩個條件，哪一個可以先用？」「要求面積，需要哪兩個向量？」。讓學生可以先停下來想。
- `a`：這一步怎麼做、**為什麼這樣做**。代數過程不要跳步：代入、展開、移項都寫出來；用到公式時說出公式名稱。
- 情境題的第一步要示範**怎麼把文字翻成數學**（設變數、畫圖、列表）。
- 用到圖形的題目，用文字描述該怎麼畫或看圖（「在坐標平面上標出 A、B 兩點…」）。
- 若有更聰明的解法，可以在最後一步補充「另解」，但主線用中等生最自然的方法。

### check（驗算）

代回原條件、估算大小、檢查範圍（機率在 0 到 1 之間、長度為正、選項合理），1–2 句。

### takeaway（心法）

一句話，下次遇到同類題可以想起來的重點，例如「看到『已知結果，問原因』的機率，就是條件機率，分母是結果發生的總機率」。

### answer_issue

答案與既有 `answer` 一致就留空字串。若你看原題後發現既有答案、題意摘要有錯，在這裡寫明（並在 `answer` 填你確認後的正確答案），我會人工複核。

## 寫作規範

- 繁體中文、台灣高中用語（例如「坐標」「向量」「行列式」）。
- **不用 LaTeX**。數學用 Unicode：x²、x³、√2、∛、π、θ、≤ ≥ ≠、×、÷、·、⇒、Σ、∫、∞、∠、△、⊥、∥；分數寫 `3/4` 或 `(a+b)/(c+d)`；向量寫「向量 AB」或 `AB→`；下標用 ₁₂₃（例如 x₁）。
- 每個 `a` 原則上 1–5 句；不要寫成整段長文，也不要只丟一條式子。
- 語氣像老師在旁邊陪學生做題：「先別急著算…」「注意這裡…」。不要用表情符號。
- 答案一律以大考中心參考答案為準（既有 `answer` 已核對過）。

## 輸出檔

- 寫到指定的 `tools/detail/<代碼><年度>.json`（代碼 A=數A、B=數B、J=數甲、Y=數乙），內容是**陣列**，每題一個物件，題組子題各一個物件；題數必須與 `tools/data` 中該卷題數相同。
- 寫完用 `python -I -c "import json;json.load(open(r'路徑',encoding='utf-8'))"` 驗證能讀取。
- 回報不超過 200 字：題數、有 `answer_issue` 的題號、遇到的問題。不要把 JSON 內容貼回來。
